Manpower Frontend Only Final

No backend needed.
No PostgreSQL needed.
No Prisma needed.
No API calls.

How to run:
1. Extract ZIP
2. Open terminal
3. cd client
4. npm install
5. npm run dev

Data storage:
- Browser localStorage

Backup:
- Go to Backup tab
- Click Full JSON Backup

Restore:
- Go to Backup tab
- Choose JSON backup file

Reports:
- Duty CSV Report
- Vendor Pending CSV

Important:
If you clear browser data, localStorage data will be removed. Take JSON backup regularly.
